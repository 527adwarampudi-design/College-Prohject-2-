# College-Prohject-2-
For this project, I used AI as a tool to help me understand, improve, and build parts of my website. I also used some code from websites I made in previous years as a starting point. For example, the little popup in the bottom corner of my website originally came from my summer website.  I reused the basic structure and changed the words, design, and information so that it worked for my Stevens website. I did something similar with some of the cards and the FAQ section.

I also used AI to help me figure out how to create the financial calculator section. Instead of just copying the code, I looked through it and learned what each part was doing. I then changed and organized the code in a way that made sense to me and fit the rest of my website.

Overall, I used AI mainly for ideas, troubleshooting, and understanding code, while using my own previous work and making my own changes to make the website fit my project.
